# Final result map

- `mcmc_primary/summary/`: authoritative synthetic CSV results used in the
  dissertation.
- `ridgecrest/completeness_summary.csv`: fitted single-mainshock completeness
  parameters and recovery time.
- `ridgecrest/mcmc_conditioned_single/forecast/`: authoritative Ridgecrest
  diagnostics and posterior-predictive summaries.
- `figures/thesis/`: the three figures included in the dissertation body and
  their compact plotting data where applicable.

Regeneratable catalogues, preliminary fits, posterior draws, supporting
figures, and obsolete result trees are excluded from the compact submission.
They can be recreated by the ordered scripts in `scripts/submission/`.
